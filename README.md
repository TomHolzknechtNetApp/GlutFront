# GlutFront
So funktioniert's: Platziere Einheiten entlang der Wege, um Gegner zu stoppen, bevor sie den Stollen erreichen. Besiegte Gegner lassen Kohle fallen – damit kaufst du neue Einheiten oder upgradest bestehende (bis Stufe 3). Steuerbar per Maus &amp; Tastatur  (Leertaste startet die nächste Welle) oder Touch – einstellbar unter ⚙️.
